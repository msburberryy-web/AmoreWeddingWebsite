သင့် Wedding Journey — အဆင့် ၈ ဆင့်

ပထမ consultation ကနေ ပွဲနေ့အထိ ခရီးစဉ် အကြမ်းဖျင်းပါ — ကိုယ့်ရက် အတိအကျကိုတော့ အဆင့်တွေ အားလုံးရဲ့ အောက်ဆုံးမှာ ရှိတဲ့ My Plan calculator နဲ့ တွက်ကြည့်ပါ။

STEP 1 · ပထမ CONSULTATION ပြီးနောက်

Rough Plan အတည်ပြုခြင်း + First Deposit

Amoré နဲ့ ပထမ consultation လုပ်ပြီးလို့ Amoré နဲ့ ဆက်လုပ်ဖို့ ဆုံးဖြတ်ရင် — wedding ရဲ့ rough plan (ရက် ခန့်မှန်း၊ guest ခန့်မှန်း၊ လိုချင်တဲ့ ပုံစံ အကြမ်း) ကို အရင် အတည်ပြုပြီး Amoré ဆီ first deposit ပေးပေးပါ။ ဒါမှ နောက်တစ်ဆင့် စလို့ ရပါမယ်။

STEP 2 · VENUE ရှာဖွေခြင်း

Venue တွေ လိုက်ကြည့်ခြင်း + Terms & Conditions စစ်ခြင်း

Venue ရှာဖွေမှု ခရီးစဉ် စပါပြီ — venue တစ်ခုချင်းကို ကြည့်ပြီး သူ့ရဲ့ Terms & Conditions ကို သေချာ စစ်ပါ (allergy / အစားအသောက် ကန့်သတ်ချက် support ရှိမရှိ အပါအဝင် — venue တိုင်းက မပေးနိုင်ပါဘူး)။ Venue contract ချုပ်ဆိုတာကိုလည်း Amoré က သင့်ကိုယ်စား ဆောင်ရွက်ပေးလို့ ရပါတယ်။ မှတ်ချက် — အစီအစဉ် ပြောင်းလို့လည်း ရပါတယ်: venue ကို အရင် ရှာကြည့်ပြီးမှ rough plan အတည်ပြု + first deposit ပေးတာလည်း ရပါတယ် (Step 1 နဲ့ Step 2 ကို အပြန်အလှန် ပြောင်းလို့ ရပါတယ်)။

STEP 3 · VENUE CHECK ပြီးနောက်

Second Deposit + FORM 1 (申込書) ပို့ခြင်း

Venue check ပြီးသွားရင် — on-site လာကြည့်တာဖြစ်ဖြစ်၊ online က စစ်တာဖြစ်ဖြစ် — အတည်ပြုဖို့ Amoré ဆီ second deposit ပေးပေးပါ။ အဲဒီနောက် FORM 1 — 申込書 (Application Form) ကို ပို့ပေးပါမယ်။ ကျန်တဲ့ form တွေနဲ့ Action Item တွေက အဲဒီနောက် ဆက်လာပါမယ် — အသေးစိတ်ကို Forms tab မှာ ကြည့်ပါ။

STEP 4 · BOOKING အတည်ပြုပြီးနောက်

Welcome & Kickoff

見積 နဲ့အတူ စာချုပ် အတည်ပြုပြီးတာနဲ့ intake form တွေနဲ့ Action Item ၄ ခုကို စဖြည့်ပါ — အသေးစိတ်ကို Forms tab မှာ ကြည့်ပါ။

STEP 5 · ပွဲမတိုင်ခင် ၃–၄ လ

ဖိတ်စာ ပေးပို့ခြင်း · အစီအစဉ် ပုံဖော်ခြင်း

ဖိတ်စာ စတင် ပေးပို့ပြီး၊ MC & Music · studio visit · web invitation · styling & decoration အတွက် တာဝန်ခံ (担当者) နဲ့ တွေ့ဆုံမယ့် ရက်တွေကို ချိန်းဆိုပါတယ်။ ဝတ်စုံနဲ့ accessories ကို ဒီ အဆင့်မှာ အပြီးသတ် ရွေးချယ်ရပါမယ်။

STEP 6 · ပွဲမတိုင်ခင် ၄ ပတ်

အသေးစိတ် အတည်ပြုခြင်း

ဧည့်သည် ဦးရေ၊ seating နဲ့ run sheet ကို အတည်ပြုပြီး program ကို ပြန်လည် သုံးသပ်ပါတယ်။ Allergy / အစားအသောက် ကန့်သတ်ချက် ရှိတဲ့ guest တွေ ရှိရင် ဒီ အဆင့်မတိုင်ခင် ကတည်းက ပြောပြထားပါ — venue တိုင်းက allergy support မပေးနိုင်ပါဘူး၊ venue နဲ့ ကြိုစစ်ထားဖို့ လိုပါတယ်။ ပါဝင်ဆောင်ရွက်မယ့် သူတွေ (အရံများ၊ လက်ဖွဲ့ထိုင်၊ အမှတ်တရ စကားပြောမယ့်သူ) ကိုလည်း အကြောင်းကြားပါ — လက်ဆောင်ပြန်ကမ်း (return gift) တွေကိုလည်း ဒီ အဆင့်မှာ ပြင်ဆင်ပြီးသား ဖြစ်ရပါမယ်။

STEP 7 · ပွဲမတိုင်ခင် ၂ ပတ်

နောက်ဆုံး 見積 နဲ့ ကျန်ငွေ လွှဲပြောင်းခြင်း

အတည်ပြုချက်တွေ အားလုံး ပြီးစီးပြီးနောက် planner က နောက်ဆုံး 見積 (final estimate) ကို ထုတ်ပေးပါတယ် — ကျန်ငွေကို အဲဒီနောက် လွှဲပြောင်းပေးပါ။

STEP 8 · WEDDING DAY

💒 မင်္ဂလာဆောင်နေ့

ပွဲနေ့ကို စိတ်အေး လက်အေး ပျော်ရွှင်စွာ ဆင်နွှဲပါ — ပြင်ဆင်မှုတွေကို team က တာဝန်ယူ ဆောင်ရွက်ပေးပါမယ်။

⚠️ အားလပ်ရက် ရှည်ကြီးနဲ့ တိုက်နေရင် — New Year / Golden Week / Obon လို အားလပ်ရက် ရှည်ကြီးက ပွဲမတိုင်ခင် နောက်ဆုံး ၂ ပတ်ထဲမှာ ပါနေရင် FINAL meeting နဲ့ Lock ရက်တွေ စောပြီး ရွှေ့ရတတ်ပါတယ် (ဥပမာ January အစောပိုင်း ပွဲတွေဆို FINAL ကို December လယ် လောက်မှာ လုပ်ရပါတယ်)။ သင့် ရက်က အဲဒီလို တိုက်နေရင် team ကို စောစော ပြောပြပေးပါ။
🔀 Meeting ရက် လွန်သွားပြီဆိုရင် — Booking နောက်ကျလို့ meeting တစ်ခု ရက်က လွန်သွားပြီဆိုရင် အဲဒီ meeting ရဲ့ အကြောင်းအရာတွေကို အနီးဆုံး လာမယ့် meeting ထဲ ပေါင်းထည့်ပြီး ဆွေးနွေးပါတယ်။ စိုးရိမ်စရာ မလိုပါဘူး — My Plan မှာ လွန်သွားတဲ့ ရက်တွေကို မီးခိုးရောင် နဲ့ ပြထားပါတယ်။

My Plan Calculator — ကိုယ့်ရက်တွေ တွက်ကြည့်ပါ

အဆင့်တွေ ကြည့်ပြီးရင် ကိုယ့် wedding date ကို ထည့်ပြီး ကိုယ်ပိုင် deadline ရက်တွေကို တွက်ကြည့်ပါ။

ရက်တွေ အားလုံးကို guideline စည်းကမ်း — Meeting 1 (−၄ လ) · Invitation (−၂ လခွဲ) · Meeting 3 + RSVP (−၁ လ) · Venue စာရင်းပိတ် (−၅ ပတ်) · လူအရေအတွက် အပြီးသတ် (−၂ ပတ်) · FINAL (−၂ ပတ်) · Data Lock (−၁ ပတ်) — နဲ့ တွက်ထားပါတယ်။ Lock ရက်တွေ အပိုင်းလိုက် မတူတာ သတိပြုပါ။

📅 အပေါ်မှာ wedding date ရွေးလိုက်ရင် သင့် deadline စာရင်း ဒီနေရာမှာ ပေါ်လာပါမယ်။

📲 Calendar ထဲ ထည့်ရန် — နည်းလမ်း ၂ မျိုး

✅ အလွယ်ဆုံး (အကြံပြုထား) — အောက်က Google Calendar list မှာ milestone တစ်ခုချင်းစီကို Add နှိပ်ရုံပါပဲ။ File download / import မလိုပါ၊ iPhone / Android / computer အကုန် အလုပ်လုပ်ပါတယ်။
📥 .ics file နည်း — computer မှာ တစ်ခါတည်း အကုန် import လုပ်ချင်ရင် (သို့) Apple Calendar အတွက် Mail နည်း သုံးချင်ရင် အောက်က download ခလုတ်ကို သုံးပါ။

📅 Google Calendar ထဲ တစ်ခုချင်း ထည့်ရန် — Add ကို နှိပ်ပါ

နှိပ်လိုက်ရင် Google Calendar (app / web) မှာ event အသင့်ဖြည့်ပြီး ပွင့်လာပါမယ် — Save နှိပ်ရုံပါပဲ။ ရက်တွေက အပေါ်က calculator တွက်တဲ့ ရက် အတိအကျပါပဲ။

    🍎 iPhone Apple Calendar / .ics file ထည့်နည်း — အရင် ဖတ်ပါ

    ⚠️ iPhone Files app ထဲမှာ ဖွင့်ရင် ရက်စာရင်း preview ပဲ မြင်ရပြီး import လုပ်လို့ မရနိုင်ပါ — ဒါ ပုံမှန်ပါပဲ၊ file ပျက်နေတာ မဟုတ်ပါဘူး။ ဒီ page ကို internet ပေါ် တင်ထားတာ မဟုတ်လို့ Files app ကနေ တိုက်ရိုက် Calendar ထဲ ထည့်ပေးတဲ့ လမ်းကြောင်း မရှိပါဘူး။

    🍎 Apple Calendar ထဲ ထည့်ချင်ရင် — .ics file ကို email နဲ့ ကိုယ့်ဆီ ပြန်ပို့ပြီး iPhone ရဲ့ Mail app ထဲက attachment ကို ဖွင့်ပါ → အဲဒီမှာ 「Add All」 ပေါ်လာပါမယ်။

    💻 Computer ရှိရင် အလွယ်ဆုံးပါ — calendar.google.com → ⚙️ Settings → Import & export → Import → .ics file ရွေးပါ။ Mac Apple Calendar ဆိုရင် file ကို double-click လုပ်ရုံပါပဲ။

    💡 အကြံပြုချက် — ဖုန်းပဲ ရှိရင် file ကို မကြိုးစားပါနဲ့၊ အပေါ်က Google Calendar Add ခလုတ်တွေကိုပဲ သုံးပါ — တူညီတဲ့ ရက်တွေ အတိုင်း ဝင်သွားပါမယ်။

    ဒီ Google Calendar link တွေနဲ့ .ics file ထဲမှာ အပေါ်က deadline ရက်တွေ အားလုံး အတူတူပါပဲ — Amoré team က ပို့တဲ့ link / file ကို client က သုံးရင် နှစ်ဖက်လုံး ရက်တူ၊ အစီအစဉ် တူ ဖြစ်နေပါမယ်။

    ရွေးပြီးသား ပုံတွေကို အရင် Folder ခွဲပြီး ပို့ထားပါ (Photos Share အပိုင်း မှာ ပို့နည်း အသေးစိတ် ရှိပါတယ်)။ နောက်မှ လဲချင်တဲ့ ပုံရှိရင် “အသစ်” လို့ မှတ်ပြီး ထပ်ပို့ပေးပါ — ဘယ်ပုံကို ဘာနဲ့ လဲတယ် ဆိုတာပါ ရေးပေးပါ။

    သီချင်း file မရှိသေးရင်?

    Final Lock ပြီးမှ guest ပြောင်းသွားရင်?

    Lock ပြီးရင် seating နဲ့ paper print တွေ စလုပ်ပြီးသား ဖြစ်လို့ ပြင်ဖို့ ခက်ပါတယ်။ ပြောင်းလဲမှု ရှိတာနဲ့ သိသိချင်း အမြန် ဆက်သွယ်ပေးပါ — လုပ်လို့ ရနိုင်တာ စစ်ပေးပါမယ်။

    Data တွေ ဘယ်ကို ပို့ရမလဲ?

    ဓာတ်ပုံနဲ့ video လို file ကြီးတွေကို Google Drive folder နဲ့၊ စာသားနဲ့ အချက်အလက်တွေကို form တွေနဲ့ ပို့တာက အရှင်းဆုံးပါ။ Chat ထဲမှာ file ကြီး ပို့ရင် အရည်အသွေး ကျသွားတတ်ပါတယ်။

    Makeup trial ရနိုင်ပါသလား?

    ရနိုင်ပါတယ် — အချိန်ချိန်းဆိုပြီး trial makeup လုပ်လို့ ရပါတယ်။ ကြိုက်တဲ့ style (natural / bold / Japanese-style) ရဲ့ reference ပုံလေးတွေ ရှိရင် ယူလာပေးပါ။

    Studio ကို ဘယ်လို လာရမလဲ?

    Message နဲ့ အချိန်ချိန်းပေးပါ — ပြီးရင် Studio (千石၊ 文京区) ကို လာပြီး ဝတ်စုံနဲ့ accessories တွေကို ကြည့်ရှု / စမ်းဝတ်နိုင်ပါတယ်။ လိပ်စာက အပေါ်က Studio card မှာ ရှိပါတယ်။

    မေးခွန်း ရှိရင် ဘယ်သူ့ကို မေးရမလဲ?

    Producer (စာချုပ် ~ kickoff) နဲ့ Planner (Step 5 ကနေ ပွဲနေ့အထိ) — နှစ်ယောက်လုံးက သင့် အခြေအနေကို မြင်တွေ့နိုင်လို့ ဘယ်သူ့ကို ပို့ပို့ အဆင်ပြေပါတယ်။ အသေးစိတ်ကို Meetings အပိုင်း မှာ ကြည့်ပါ။

    အပြင်က အစားအစာ / အရက် (food safety နဲ့ venue စည်းကမ်း အရ — baby food ကိုတော့ ကြိုအသိပေးရင် ခွင့်ပြုပါတယ်)၊ ခန်းမ အချို့မှာတော့ gift / return gift တွေပါ ပါဝင်ပါတယ်။

    V9

    အချိန် ကျော်လွန်ခြင်း

    Venue အသုံးပြုချိန် ကျော်လွန်ရင် extra room fee ရှိနိုင်ပြီး၊ နောက်မှာ ဆက်တိုက် event ရှိနေရင် extension ရနိုင်မယ် မဟုတ်ပါဘူး။

    V10

    ပစ္စည်း ပျက်စီးမှု

    Guest / vendor / client ကြောင့် (ကလေးများ၊ အရက်မူးသူများ အပါအဝင်) ပျက်စီးမှု ဖြစ်ရင် repair cost + damage fee ကို client ဘက်က တာဝန်ယူရပါမယ်။

    V11

    မမျှော်လင့်တဲ့ အခြေအနေ (ငလျင် / ကပ်ရောဂါ)

    အခြေအနေပေါ် မူတည်ပါတယ် — Government restriction ကြောင့် ပွဲ မဖြစ်နိုင်ရင် contract auto-cancel ဖြစ်နိုင်ပြီး၊ refund / adjustment ကို venue policy နဲ့အညီ ဆောင်ရွက်ပေးပါမယ်။

    V12

    ပြင်ဆင်ချိန် အပို ကုန်ကျစရိတ်

    အလှဆင်ပြင်ဆင်မှု (decoration preparation)၊ rehearsal နဲ့ ပွဲမတိုင်ခင် ဓာတ်ပုံရိုက်ကူးမှု (pre-event shooting) အတွက် လိုအပ်တဲ့ အချိန်ကို ပုံမှန်အားဖြင့် Venue Rental Fee အပို အဖြစ် တွက်ချက်ပြီး quote ထဲမှာ ထည့်သွင်းပေးပါမယ်။
